Warden

An automated security guard for changes to live software.

It approves boring ones, blocks dangerous ones, asks a human only when unsure, keeps an unerasable log, and cannot be talked into a bad decision by an AI assistant that was tricked.

Every button below replays a run that was recorded from the real code. Nothing runs live on this page.

Try it

Pick one. The last one is the surprise.

Each attack hides instructions somewhere the AI assistant reads: the change's description, a tool's reply, a tool's help text, a message from the server, or a fake tool. Some split the instructions across two places.

Press a button to start.

Each replay prints what the AI assistant asked for, step by step, then what Warden decided. A freeze is a period when no live changes are allowed.
