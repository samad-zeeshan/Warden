Warden

It is an automated security guard for changes to live software.

It approves safe changes and blocks dangerous ones. It asks a person only when it is unsure. Its log shows any later edit. A tricked AI assistant cannot talk it into a bad decision.

Each button below replays a past run of the real code. Nothing runs live on this page.

01 The replays

Try it

Pick one. The last one is the surprise.

Each attack hides instructions in a place that the AI assistant reads. That place can be the description of the change, a tool's reply or a tool's help text. It can also be a message from the server or a fake tool. Some attacks put the instructions in two places.

Press a button to start.

Each replay shows the requests of the AI assistant in order. Then it shows the decision of Warden. A freeze is a period when the team allows no live changes.
